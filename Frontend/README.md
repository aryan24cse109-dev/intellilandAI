# IntelliLandAI Frontend

React-based frontend for the IntelliLandAI platform.

## Responsibilities

The frontend provides interfaces for:

- Authentication
- Dashboard
- Document management
- Document processing
- Validation review
- Human verification
- GIS visualization
- Audit history

## Stack

- React
- Vite
- React Router
- Axios
- Leaflet
- React-Leaflet
- CSS

## Run

```bash
npm install
npm run dev
